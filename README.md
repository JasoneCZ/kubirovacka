# Kubírovačka

Webová kubírovačka pro iPhone i Android. Funguje i bez signálu a zakázky ukládá přímo v telefonu.

**Otevřít:** https://jasonecz.github.io/kubirovacka/

## Jak si ji dát na plochu
- **iPhone (Safari):** Sdílet → Přidat na plochu → Přidat
- **Android (Chrome):** nabídka ⋮ → Přidat na plochu / Nainstalovat aplikaci

## Co umí
- **Kulatina:** délka + průměr, srážka na kůru podle dřeviny (Doporučená pravidla pro měření a třídění dříví v ČR, tab. 6.9), objem podle Huberova vzorce, jakost I–VI, oddenek, „bez kůry“
- **Suráky:** kategorie × 0,1 m³ × počet kusů
- **Sumář:** kulatina, suráky a dohromady (kusy, oddenky, objem, průměrná hmotnatost), cena podle dřevin, export CSV
- **Zakázky** s JPRL, záloha do souboru a obnova ze zálohy

Data se nikam neodesílají, zůstávají jen v telefonu.
